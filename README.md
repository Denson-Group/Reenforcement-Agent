# Reinforcement-Learning Agent

Sequential open, hold, hedge, and close policy research for the Denson Group options trading system. It consumes point-in-time data and forecasts through the shared environment while using canonical exposure, cost, P&L, and risk behavior.

The authoritative system context is pinned under [`governance/`](./governance/). Start by reading [`AGENTS.md`](./AGENTS.md).

The GitHub repository currently uses the historical name `Reenforcement-Agent`; documentation uses the correct term “reinforcement learning.”
